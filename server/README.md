# Bolt Survival — тестовый WebSocket-сервер

Сервер принимает WebSocket-подключения на порту **7777**, поддерживает до **20 игроков** и рассылает состояние игроков каждые 100 мс. Это серверная основа; Android-клиент пока ещё нужно подключить отдельно.

## Сборка в GitHub Codespaces

Если старый сервер запущен, останови его сочетанием **Ctrl+C**. Затем выполни:

```bash
git pull --ff-only origin master
cmake -S server -B server/build
cmake --build server/build -j2
```

## Запуск

```bash
./server/build/BoltSurvivalServer
```

Сервер слушает порт 7777. Во вкладке **ПОРТЫ** укажи для него видимость **Общедоступный**, если к нему будут подключаться друзья. Клиент подключается по адресу WebSocket вида `wss://ИМЯ-ПЕРЕСЫЛАЕМОГО-АДРЕСА/` (без завершающего HTTP-пути).

## Протокол

WebSocket-текстовые сообщения содержат строки:
- Клиент → сервер: `JOIN name`
- Клиент → сервер: `MOVE x y z yaw`
- Клиент → сервер: `PING`
- Сервер → клиент: `WELCOME id max`, `STATE count ...`, `PONG`

**Важно:** это тестовая основа без авторизации, шифрования на уровне приложения, защиты от читов и постоянного хранения мира. Не используй её как публичный production-сервер.
