# Bolt Survival — тестовый онлайн-сервер

Это первый отдельный серверный прототип для проверки сетевого подключения. Он пока не интегрирован в Android APK и не синхронизирует игровой мир.

## Сборка в GitHub Codespaces

```bash
cmake -S server -B server/build
cmake --build server/build -j2
```

## Запуск

```bash
./server/build/BoltSurvivalServer
```

Сервер слушает TCP-порт **7777**, принимает до **20** подключений.

В Codespaces открой вкладку **PORTS**, добавь порт `7777` и установи видимость **Public** только если друзьям нужно подключаться извне. Не публикуй адрес сервера в открытых местах.

## Проверка двух клиентов

Открой второй и третий терминалы Codespaces и запусти в каждом:

```bash
python3 -c 'import socket,time; s=socket.create_connection(("127.0.0.1",7777)); s.settimeout(2); s.sendall(b"JOIN Friend1\\n"); print(s.recv(4096).decode()); time.sleep(30)'
```

Во втором терминале замени имя на `Friend2`. В серверном терминале появятся подключения и счётчик игроков.

Протокол строковый: `JOIN name\n`, `MOVE x y z yaw\n`, сервер отвечает `WELCOME id max\n` и рассылает `STATE ...\n`.

**Важно:** это тестовая основа без авторизации, шифрования, защиты от читов и постоянного хранения мира. Не используй её как публичный production-сервер. Следующий шаг — подключить Android-клиент и отображать других игроков.
